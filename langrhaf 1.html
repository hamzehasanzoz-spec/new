الدليل الشامل لهندسة الوكلاء (LangGraph)

كيف ننقل "كوتش AI" من مجرد تطبيق دردشة إلى نظام تعليمي متعدد الوكلاء (Multi-Agent System)

📅 التحديث القادم (المرحلة 9) 🎯 الهدف: القضاء على التشتت والهلوسة 🛠️ التقنيات: LangGraph.js, LangChain, Node.js

01 ما هو LangGraph ولماذا نحتاجه؟

المشكلة الحالية (RAG الخطي): في الكود الحالي، سؤال الطالب يمر بخط مستقيم: (سؤال -> بحث -> إجابة). هذا يسبب الهلوسة إذا كان البحث سيئاً، ولا يسمح للـ AI بتصحيح مساره.

الحل (LangGraph): هو إطار عمل لبناء تطبيقات AI على شكل رسوم بيانية (Graphs). تخيل أن الـ AI لديه "خريطة طريق" يمكنه التنقل فيها، والرجوع للخلف إذا اكتشف خطأً، واستخدام وكلاء متخصصين لكل مهمة.

02 المكونات الأساسية لـ LangGraph

المكونالشرحمثال في كوتش AI
State (الحالة) الذاكرة التي تنتقل بين الخطوات. يجب أن تكون محددة بـ TypedDict. نص السؤال، ملفات الطالب، الكلية، السنة، نتائج البحث، الإجابة النهائية.
Nodes (العقد) الخطوات أو الوكلاء المتخصصون الذين يقومون بعمل ما (دوال JavaScript). وكيل البحث في الملفات، وكيل توليد الاختبار، وكيل التقييم، وكيل الرد.
Edges (الحواف) الأسهم التي تحدد الانتقال من عقدة لأخرى. يمكن أن تكون شرطية (Conditional). إذا كان السؤال عن "دواء" -> اذهب لوكيل الأدوية. إذا كان "فسيولوجيا" -> اذهب لوكيل المناهج.
Checkpointer (نقاط الحفظ) حفظ حالة المحادثة في قاعدة البيانات (Supabase) لاستئنافها لاحقاً. الطالب أغلق المتصفح وعاد بعد ساعتين. يجد الاختبار كما تركه بالضبط.

03 كيف سيغير LangGraph من أداء كوتش AI؟

التحسين الأول

🔄 RAG وكيلي (Agentic RAG)

بدلاً من البحث مرة واحدة، سنبني حلقة تصحيح.
1. وكيل البحث يجلب 20 جزءاً.
2. وكيل التقييم يقرأها ويقول: "هل هذه الأجزاء تجيب على السؤال؟".
3. إذا قال "لا"، يقوم وكيل إعادة الصياغة بتغيير السؤال والبحث مرة أخرى.
النتيجة: إجابات دقيقة 100% ولا هلوسة.

التحسين الثاني

👷 نمط المشرف والعمال

بدلاً من نموذج واحد ضخم يشتت، سنبني فريقاً:
• المشرف (Supervisor): يقرأ السؤال ويقرر من سيجيب.
• وكيل الفارماكولوجي: خبير بالأدوية والجرعات.
• وكيل الباثولوجي: خبير بالأمراض.
• وكيل الاختبارات: خبير بتوليد الأسئلة.
النتيجة: تخصص أعلى لكل وكيل، وبالتالي دقة أعلى.

التحسين الثالث

🧠 الذاكرة وإدارة الحالة

سيحفظ LangGraph حالة كل طالب. يعرف ماذا أجاب في السؤال الأول، وما هي نقاط ضعفه. هذا يسمح للـ AI بتخصيص الأسئلة التالية بناءً على أداء الطالب في الأسئلة السابقة.

التحسين الرابع

🚦 التوجيه الذكي

ليس كل سؤال يحتاج بحثاً. إذا قال الطالب "مرحباً"، سيجيبه الوكيل مباشرة دون إهدار تكلفة البحث في الملفات.

04 خارطة الطريق التنفيذية (كيف تبرمج هذا في Node.js؟)

المتطلبات المسبقة: يجب أن تكون المنصة تعمل حالياً (الشات والبحث). LangGraph هو "الترقية" وليس "البديل". سنستخدم مكتبة @langchain/langgraph في بيئة Node.js (Vercel).

المرحلة 1: بناء الحالة (State) والعقد (Nodes) الأساسية

نحدد شكل البيانات التي ستمر بين الوكلاء (AgentState).

import { StateGraph, Annotation } from "@langchain/langgraph"; // 1. تعريف الحالة const AgentState = Annotation.Root({ question: Annotation<string>, context: Annotation<string[]>, finalAnswer: Annotation<string>, retryCount: Annotation<number>({ reducer: (x, y) => y, default: () => 0 }), }); // 2. بناء العقد (النماذج) const workflow = new StateGraph(AgentState) .addNode("router", routerNode) .addNode("search", searchNode) .addNode("generate", generateNode);

المرحلة 2: بناء المشرف (Supervisor Router)

عقدة تقرأ السؤال وتقرر أين تذهب.

async function routerNode(state) { // استخدام Groq لتصنيف السؤال const category = await classifyIntent(state.question); if (category === "greeting") return "generate"; // لا يحتاج بحث if (category === "medical") return "search"; // يحتاج بحث return "search"; } // إضافة الحواف الشرطية workflow.addConditionalEdges("router", (state) => { // العودة إلى العقدة المناسبة });

المرحلة 3: تطبيق RAG الوكيلي (Agentic RAG)

إضافة عقدة التقييم (Grader) لتصحيح مسار البحث.

async function graderNode(state) { const isRelevant = await checkRelevance(state.context, state.question); if (isRelevant) return "generate"; if (state.retryCount > 2) return "generate"; // لا تدخل في حلقة لا نهائية return "rewrite_query"; // إعادة صياغة السؤال والبحث }

المرحلة 4: الذاكرة الدائمة (Checkpointing)

ربط LangGraph بـ Supabase لحفظ حالة الطالب.

import { PostgresSaver } from "@langchain/langgraph-checkpoint-postgres"; const checkpointer = await PostgresSaver.fromConnString(process.env.SUPABASE_DB_URL); const app = workflow.compile({ checkpointer });

05 المهارات التي ستكتسبها من هذه المرحلة

🧠 مفاهيم هندسية متقدمة

  • Stateful Applications: بناء تطبيقات تحتفظ بالذاكرة وتعرف سياقها.
  • Agentic Workflows: تصميم حلقات اتخاذ قرار للـ AI (Self-Correction).
  • Graph Theory: فهم كيفية ربط العقد وتحديد مسارات التنفيذ.

💻 أدوات ومكتبات

  • LangGraph.js: المكتبة الأساسية (متوافقة مع Node.js/Vercel).
  • LangChain.js: لربط الأدوات والنماذج.
  • Zod: للتحقق من صحة البيانات في العقد (Nodes).
