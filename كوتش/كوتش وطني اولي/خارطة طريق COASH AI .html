📌 نظرة عامة

كوتش AI هو تطبيق ويب ذكي مخصص لمساعدة طلاب الطب في سوريا على التحضير للامتحان الوطني (NMLE). يعتمد التطبيق على استبيان شخصي شامل لتخصيص تجربة كل طالب، ثم يستخدم نماذج ذكاء اصطناعي مجانية للدردشة الطبية، مع خطة لدمج تتبع أداء أسبوعي، اختبارات ذكية، ولوحة تحكم متقدمة.

React 18 Vite 5 Supabase (Auth + DB) OpenRouter AI Vercel (Hosting + Serverless) Git + GitHub

🛠️ المكدس التقني بالتفصيل

🎨 الواجهة الأمامية
React 18 + Vite 5 — سرعة تطوير عالية، HMR فوري.
Styling: Inline styles (قابل للترحيل لـ Tailwind/CSS Modules لاحقًا).
🗄️ البيانات
Supabase (PostgreSQL مُدار) + Auth + Row Level Security.
مجاني حتى 500MB + 50K مستخدم نشط شهريًا.
🤖 الذكاء الاصطناعي
OpenRouter — بوابة موحدة لنماذج مجانية متعددة.
Fallback chain: جرّب نموذجًا، إن فشل انتقل للتالي.
الخطة: إضافة Groq كطبقة ثانية.
🚀 النشر
Vercel — نشر تلقائي من GitHub + Serverless Functions.
الخطة المجانية: 100GB bandwidth + سيرفرات serverless سخية.

🔐 متغيرات البيئة (Vercel)

الاسم الغرض Environment
VITE_SUPABASE_URL رابط مشروع Supabase All
VITE_SUPABASE_ANON_KEY مفتاح Supabase العام All
OPENROUTER_KEY مفتاح OpenRouter للـ AI (سيرفر فقط) All
GROQ_KEY (مستقبلي) مفتاح Groq كطبقة احتياطية All
SITE_URL (اختياري) يُمرَّر إلى OpenRouter في الـ headers All
⚠️ مهم: مفاتيح AI بدون بادئة VITE_ — لأنها سرية ولا يجب أن تظهر في المتصفح.

📐 قواعد التنسيق والالتزام

عند إضافة ميزة جديدة:

  1. حدّث هذا الملف (أضف صفًا في الجدول)
  2. ارفع التعديل على GitHub مع رسالة commit واضحة
  3. اختبر محليًا أولًا (npm run dev)
  4. ثم ارفع إلى Vercel
  5. حدّث حالة المهمة: قيد التنفيذ → مكتمل

عند حدوث خطأ:

  1. افحص Browser Console (F12)
  2. افحص Vercel Logs → Functions
  3. سجّل الخطأ في قسم "سجل الأخطاء" أدناه
  4. حدّد السبب الجذري (root cause) قبل الحل
