📌 نظرة عامة

كوتش AI — منصة ذكية متكاملة لطلاب الطب في سوريا للتحضير للامتحان الوطني (NMLE). تجمع بين استبيان مخصص، دردشة AI مع RAG، توليد اختبارات MCQ، محاكاة امتحان، بنك أخطاء، تتبع أداء، تصدير PDF، وضع ليلي، ودعم الجوال.

React 18 Vite 5 Supabase (Auth + DB + pgvector) Groq API ×2 OpenRouter (احتياطي) Jina AI (Embeddings) Vercel Edge jsPDF + html2canvas
