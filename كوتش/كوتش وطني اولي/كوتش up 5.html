📌 نظرة عامة

كوتش AI — مساعد ذكي متكامل لطلاب الطب في سوريا للتحضير للامتحان الوطني (NMLE). يجمع بين استبيان شخصي، دردشة AI مع RAG، رفع ملفات، توليد اختبارات MCQ، محاكاة امتحان بمؤقت، تتبع أداء أسبوعي، ونظام Streak للتحفيز.

React 18 Vite 5 Supabase (Auth + DB + pgvector) OpenRouter AI Jina AI (Embeddings) Vercel Serverless Tailwind-style CSS

🚨 التحديات الحالية

1. Groq محجوب جغرافيًا في سوريا

Groq يستخدم Cloudflare protection يكتشف VPNs المعروفة ويحجبها. الحل: صديق في الإمارات يُنشئ الحساب ويعطيك المفتاح (يعمل من أي مكان بعد إنشائه).

2. OpenRouter Rate Limit (50 طلب/يوم)

بدون رصيد، الحد اليومي 50 طلب. الحل: رصيد $10 يرفعه إلى 1000 طلب/يوم. أو تعدد المزودين.

3. Voyage AI يحتاج بطاقة ائتمان

تم الحل: التحول إلى Jina AI — مجاني 10M توكن بدون بطاقة.

💡 ملاحظات مهمة للمستقبل

عند إضافة ملف جديد في VS Code:

استخدم git add . بدل أسماء الملفات — لضمان رفع كل الملفات الجديدة. (تكررت مشكلة "ملف مفقود" مرتين)

عند تغيير متغيرات VITE_*:

يتطلب Redeploy كامل بدون Cache. لأنها تُدمج وقت البناء.

قبل مشاركة أي مفتاح:

لا تشارك أي مفتاح API في صورة أو رسالة. إذا حصل، أنشئ مفتاحًا جديدًا فورًا.

عند اختبار الموقع:

استخدم Production URL فقط (بدون hash مثل -ozsulohfc-). روابط Preview قد تُسبب ارتباكًا.
