🩺 كوتش AI

توثيق المشروع وخارطة الطريق — منصة الامتحان الوطني للطب في سوريا

📅 آخر تحديث: 10 أكتوبر 2026 🟢 الحالة: v0.2 (يعمل بشكل مستقر) 🔗 new-udf9.vercel.app

📌 نظرة عامة

كوتش AI هو تطبيق ويب ذكي مخصص لمساعدة طلاب الطب في سوريا على التحضير للامتحان الوطني (NMLE). يعتمد على استبيان شخصي شامل لتخصيص تجربة كل طالب، ثم يستخدم نماذج ذكاء اصطناعي مجانية للدردشة الطبية، مع خطة لدمج RAG (قراءة ملفات الطالب)، تتبع أداء أسبوعي، اختبارات ذكية، ولوحة تحكم متقدمة.

React 18 Vite 5 Supabase (Auth + DB) OpenRouter AI Vercel Edge Runtime Git + GitHub

🚀 الرؤية المستقبلية (v1.0)

الهدف: مساعد ذكي شخصي لكل طالب طب سوري، يفهم ملفاته، يتابع أداءه أسبوعيًا، ويولّد له امتحانات مخصصة.
📚 RAG كامل
الطالب يرفع ملفاته (PDF, DOCX) → النظام يستخرج النص → يخزنه → الـ AI يجيب من داخل الملفات.

كل إجابة تُبنى على بيانات الطالب: مواده الضعيفة، لغته، طريقته المفضلة.

مجاني للمستخدم العادي، مدفوع لميزات متقدمة (نماذج أقوى، ملفات أكثر).
