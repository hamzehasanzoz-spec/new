أهم 20 سؤال
ما مرحلتك الحالية؟
(سنة رابعة/خامسة/متخرج/إعادة) وما جامعتك؟

هل الامتحان الذي تستعد له هو الوطني السوري؟
وما المواد أو المحاور المقررة عليك بالضبط؟

كم ساعة دراسة فعالة تقدر تدرس يوميًا وأسبوعيًا؟
وما أفضل أوقاتك؟

شو هدفك من العلامة؟
(نجاح فقط / معدل جيد / ترتيب عالي / اختصاص معين)

كيف تقيّم مستواك الحالي في كل مادة؟
(ضعيف / متوسط / جيد / ممتاز)

ما أصعب 3 مواد أو فصول عندك؟ وليش؟
(حفظ / فهم / ربط سريري / أسئلة)

ما نوع الأسئلة اللي يربكك؟
(MCQ / حالات سريرية / صور / تشخيص تفريقي / أرقام)

كيف تدرس عادة؟
(قراءة / تلخيص / بطاقات / فيديو / حل أسئلة / شرح لغيرك)

شو أفضل طريقة تفهم فيها؟
(شرح مبسط / مخططات / جداول / أمثلة سريرية / مقارنات / منمنمات)

بأي لغة تفضل الشرح؟
(عربي / إنجليزي / مزيج) وهل المصطلحات تكون إنجليزية؟

شو المصادر المتوفرة عندك؟
(كتب / ملخصات / بنوك أسئلة / فيديوهات / تطبيقات)

هل الإنترنت والجهاز متاحين دائمًا؟
وهل تدرس أونلاين أم أوفلاين؟

شو أكبر عائق بيواجهك؟
(تشتت / نسيان / وقت / إرهاق / قلق / ملل / ضغط أهل)

كيف تتعامل مع المراجعة والنسيان؟
(نظام يومي / أسبوعي / عشوائي / ما في نظام)

تفضل خطة صارمة أم مرنة؟
وكم مرة تريد إعادة تعديلها؟

كيف تريد الـ AI يساعدك؟
(شرح / تلخيص / يسألك / يصحح / جدول / تحفيز / محاكاة امتحان)

هل تريد اختبارات قصيرة بعد كل جلسة؟
كم سؤال؟ وتصحيح فوري أم مفصل؟

كيف تريد قياس تقدمك؟
(نسبة إنجاز / درجات / ثبات مراجعة / تقليل أخطاء)

هل عندك ظروف خاصة أو تفضيلات للتنبيهات؟
(عمل / مرض / سفر / عائلة / وقت تذكير / مكافآت)

نصائح مهمة حتى يخدم الـ AI الطالب بشكل فردي
خلي الأسئلة 6–10 و 14–15 مفتوحة أكثر، والباقي خيارات.

استخدم أسئلة تفريعية حسب الجواب: إذا قال ضعيف بالباثولوجيا، اسأله عن الفصول والمواضيع الفرعية.

لا تكتفِ بالاستبيان مرة واحدة. الأهم إنك تغذي الـ AI ببيانات أداء أسبوعية:
أي مادة؟ كم سؤال؟ نسبة الصحيح؟ نوع الخطأ؟ كم وقت أخذ؟

خلي الاستبيان قابل للتحديث كل أسبوع أو أسبوعين.
